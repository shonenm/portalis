# Parser — Спецификация

## Роль

`Parser` отвечает за парсинг ANSI-эскейп последовательностей и обновление состояния терминала. Он интерпретирует CSI-последовательности, OSC-коды, управляющие символы и обновляет буфер вывода экрана.

## API

### Конструктор

```go
func NewParser(screen *Screen) *Parser
```

Создаёт новый парсер для заданного экрана.

**Параметры:**
- `screen` — указатель на объект `Screen`, к которому применяется парсинг

**Возвращает:**
- указатель на `Parser`

---

## Методы

### SetCWDCallback

```go
func (p *Parser) SetCWDCallback(fn func(string))
```

Устанавливает обратный вызов, который срабатывает при изменении рабочей директории.

**Параметры:**
- `fn` — функция, принимающая путь к рабочей директории

---

### Feed

```go
func (p *Parser) Feed(data []byte)
```

Подаёт байтовую последовательность на вход парсера.

**Параметры:**
- `data` — байтовый массив для обработки

**Поведение:**
- Обрабатывает каждый байт последовательно через `feedByte`
- Обрабатывает полный UTF-8 последовательности
- Обрабатывает ANSI-эскейп последовательности (CSI, OSC)

---

## Внутреннее состояние

### Типы

#### Parser

```go
type Parser struct {
    screen    *Screen
    state     ansiState
    buf       strings.Builder
    utf8Buf   []byte
    onCWD     func(string)
    lastCWD   string
}
```

#### ansiState

```go
type ansiState int

const (
    stateNormal ansiState = iota  // 0 — обычное состояние, ASCII + данные
    stateEscape                   // 1 — ожидание '[' или ']'
    stateCSI                      // 2 — внутри CSI-последовательности
    stateOSC                      // 3 — внутри OSC-последовательности
    statePaste                    // 4 — внутри bracketed paste
)
```

## Внутренние функции

### utf8Valid

```go
func utf8Valid(buf []byte) bool
```

Проверяет, является ли байтовый массив законченной валидной UTF-8 последовательностью.

**Параметры:**
- `buf` — байтовый массив

**Возвращает:**
- `true` если последовательность валидна, `false` иначе

---

### flushUtf8

```go
func (p *Parser) flushUtf8()
```

Обработывает неполную UTF-8 последовательность, эмитируя символ замены.

---

### parseParams

```go
func parseParams(s string) []int
```

Парсит строку параметров CSI в слайс целых чисел.

**Параметры:**
- `s` — строка параметров (разделена точью-запятой)

**Возвращает:**
- `[]int` — массив параметров (пустые сегменты → 0)

---

### extractOSC7Path

```go
func extractOSC7Path(s string) string
```

Извлекает абсолютный путь файловой системы из OSC 7 payload.

**Поддерживаемые формы:**
- `file://hostname/path` → `/path`
- `/absolute/path` → `/absolute/path`

**Параметры:**
- `s` — OSC payload

**Возвращает:**
- Абсолютный путь или пустая строка

---

### handleSGR

```go
func (p *Parser) handleSGR(params []int)
```

Обработка SGR (Select Graphic Rendition) CSI-последовательностей.

**Параметры:**
- `params` — массив параметров

**Поддерживаемые коды:**
- `0` — сброс атрибутов
- `1` — жирный
- `2` — тусклый
- `3` — курсив
- `4` — подчёрнутый
- `5` — мигание
- `7` — инверсия
- `8` — скрытый
- `9` — зачёркнутый
- `22` — сброс жирного/тусклого
- `23` — сброс курсива
- `24` — сброс подчёркивания
- `25` — сброс мигания
- `27` — сброс инверсии
- `28` — сброс скрытого
- `29` — сброс зачёркивания
- `30-37` — стандартные цвета текста
- `38;5;N` — 256-цвет (5)
- `38;2;R;G;B` — RGB (2)
- `39` — сброс цвета текста
- `40-47` — стандартные цвета фона
- `48;5;N` — 256-цвет (5)
- `48;2;R;G;B` — RGB (2)
- `49` — сброс цвета фона
- `90-97` — яркие стандартные цвета текста
- `100-107` — яркие стандартные цвета фона

---

### ansi256Color

func ansi256Color(n int) lipgloss.Color

Преобразует индекс 256-цветной палитры в `lipgloss.Color`.

**Параметры:**

## CSI-последовательности

### Управление курсором

| Код | Описание |
|-----|----------|
| `CSI <n> A` | Курсор вверх на n строк |
| `CSI <n> B` | Курсор вниз на n строк |
| `CSI <n> C` | Курсор вправо на n колонок |
| `CSI <n> D` | Курсор влево на n колонок |
| `CSI <n> E` | Курсор на n строк вниз, в колонку 0 |
| `CSI <n> F` | Курсор на n строк вверх, в колонку 0 |
| `CSI <n> G` | Курсор в колонку n+1 |
| `CSI <row>;<col> H` | Установить курсор |
| `CSI <row>;<col> f` | Установить курсор |

### Очистка экрана

| Код | Описание |
|-----|----------|
| `CSI J` | Очистить экран |
| `CSI 0J` | Очистить с курсора |
| `CSI 1J` | Очистить до курсора включительно |
| `CSI 2J` | Очистить всё, курсор в (0,0) |

### Очистка строки

| Код | Описание |
|-----|----------|
| `CSI K` | Очистить строку |
| `CSI 0K` | Очистить с курсора |
| `CSI 1K` | Очистить влево от курсора |
| `CSI 2K` | Очистить всю строку |

### Область прокрутки

| Код | Описание |
|-----|----------|
| `CSI <top>;<bottom> r` | Установить область прокрутки |

### Управление режимами

| Код | Описание |
|-----|----------|
| `CSI ? h` / `CSI ? l` | Установить / сбросить DEC private режим |
| `CSI > h` / `CSI > l` | Установить / сбросить другой private режим |

#### Поддерживаемые DEC-параметры

| Параметр | Режим |
|----------|-------|
| `1` | application cursor keys |
| `25` | видимость курсора |
| `1049` | альтернативный буфер экрана |
| `2004` | bracketed paste |
| `2026` | синхронизированный вывод |

### Управляющие ESC-последовательности

| Код | Описание |
|-----|----------|
| `ESC ( B` | G0 Latin-1 / ASCII |
| `ESC ( 0` | G0 DEC Special Graphics |
| `ESC ) B` | G1 Latin-1 / ASCII |
| `ESC ) 0` | G1 DEC Special Graphics |
| `ESC 7` | сохранить курсор (DECSC) |
| `ESC 8` | восстановить курсор (DECRC) |
| `ESC D` | index (курсор вниз) |
| `ESC E` | next line (курсор вниз, колонка 0) |
| `ESC M` | reverse index (курсор вверх, прокрутка области вниз) |
| `SO` (0x0e) | переключиться на G1 |
| `SI` (0x0f) | переключиться на G0 |

### Редактирование строки

| Код | Описание |
|-----|----------|
| `CSI <n> @` | вставить n символов (ICH) |
| `CSI <n> P` | удалить n символов (DCH) |
| `CSI <n> X` | стереть n символов (ECH) |
| `CSI <n> L` | вставить n строк в области прокрутки (IL) |
| `CSI <n> M` | удалить n строк в области прокрутки (DL) |
| `CSI <n> S` | прокрутить область вверх (SU) |
| `CSI <n> T` | прокрутить область вниз (SD) |
| `CSI <n> d` | абсолютная вертикальная позиция (VPA) |
| `CSI <n> G` | абсолютная горизонтальная позиция (HPA) |

### Управление курсором

| Код | Описание |
|-----|----------|
| `CSI <n> A` | Курсор вверх на n строк |
| `CSI <n> B` | Курсор вниз на n строк |
| `CSI <n> C` | Курсор вправо на n колонок |
| `CSI <n> D` | Курсор влево на n колонок |
| `CSI <n> E` | Курсор на n строк вниз, в колонку 0 |
| `CSI <n> F` | Курсор на n строк вверх, в колонку 0 |
| `CSI <n> G` | Установить курсор в колонку n |
| `CSI <n> d` | Установить курсор в строку n |
| `CSI <row>;<col> H` | Установить курсор |
| `CSI <row>;<col> f` | Установить курсор |

### Bracketed paste

| Код | Описание |
|-----|----------|
| `CSI 200~` | Включить bracketed paste |
| `CSI 201~` | Выключить bracketed paste |

### Скроллинг

| Код | Описание |
|-----|----------|
| `CSI <n> S` | Прокрутить область вверх (SU) |
| `CSI <n> T` | Прокрутить область вниз (SD) |
| `ESC M` | Reverse index (курсор вверх, прокрутка вниз) |
| `ESC D` | Index (курсор вниз) |
| `ESC E` | Next line (курсор вниз, колонка 0) |

## OSC-последовательности

### OSC 7 — рабочая директория

```
OSC 7 ;file://hostname/path BEL
OSC 7 ;/absolute/path BEL
```

При обработке вызывается `SetCWDCallback`, если путь отличается от `lastCWD`.

---

## Bracketed paste

При вхождении в `statePaste` каждый входящий байт эмитируется как rune через `screen.Put()`.

Выход из состояния:
```
CSI 201~ → stateNormal
CSI 200~ → statePaste
```

---

## Unicode и UTF-8

Парсер обрабатывает многобайтовые UTF-8 последовательности, собирая их в `utf8Buf` до полной валидации через `utf8.Valid()`.

Неполные последовательности эмитируются как `\ufffd` (замена).

---

## Управление символом возврата каретки

- `\r` — сбрасывает столбец в 0, сбрасывает `wrapPending`
- `\n` — увеличивает строку, если `wrapPending` — ведёт себя как `\r\n`

---

## Управляющий символ обратного пробела

`\b` — уменьшает столбец курсора на 1, если он > 0.

---

## Управляющий символ табуляции

`\t` — перемещает курсор в следующее позиционированное поле (кратное 8).

---

## Цветовая палитра

### Стандартные 16 цветов (0-15)

| Индекс | Цвет | Hex |
|--------|------|-----|
| 0 | чёрный | `#000000` |
| 1 | красный | `#800000` |
| 2 | зелёный | `#008000` |
| 3 | жёлтый | `#808000` |
| 4 | синий | `#000080` |
| 5 | маджента | `#800080` |
| 6 | циан | `#008080` |
| 7 | белый | `#c0c0c0` |
| 8 | серый | `#808080` |
| 9 | красный яркий | `#ff0000` |
| 10 | зелёный яркий | `#00ff00` |
| 11 | жёлтый яркий | `#ffff00` |
| 12 | синий яркий | `#0000ff` |
| 13 | маджента яркий | `#ff00ff` |
| 14 | циан яркий | `#00ffff` |
| 15 | белый яркий | `#ffffff` |

### 6x6x6 куб (16-231)

Формула: `r = (n-16)/36`, `g = (n/6)%6`, `b = n%6`

### Оттенки серого (232-255)

Видимость: `(n-232)*10 + 8`
