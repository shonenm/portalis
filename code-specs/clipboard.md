# Спецификация: clipboard.go

## Обзор

Пакет `portalis` предоставляет функции для работы с системным буфером обмена.
Поддерживаются операции копирования текста и изображений на macOS, Linux (X11) и Wayland.

## Публичный API

### copyToClipboard

```go
func copyToClipboard(lines []string)
```

Отправляет заданный текст (соединённый новыми строками) в системный буфер обмена.

**Параметры:**
- `lines []string` — текст, разделённый на строки. Каждая строка будет отделена символом `\n`.

**Поведение:**
- Если передан пустой текст, функция ничего не делает.
- Последовательно пытается использовать следующие инструменты:
  1. `pbcopy` (macOS)
  2. `xclip` (Linux X11)
  3. `xsel` (Linux X11)
  4. `wl-copy` (Wayland)
- При успешном выполнении возвращает сразу.
- Если ни один инструмент недоступен или не работает, функция завершается без возврата ошибки.

**Пример:**
```go
copyToClipboard([]string{"Hello", "World"})
```

---

### pasteFromClipboard

```go
func pasteFromClipboard() (text string, imagePath string, err error)
```

Возвращает содержимое системного буфера обмена.

**Возврат:**
- `text string` — текстовое содержимое буфера обмена.
- `imagePath string` — путь к файлу изображения, если буфер содержит изображение.
- `err error` — ошибка, если буфер обмена недоступен или не удалось определить содержимое.

**Поведение:**
- Определяет поддерживаемую платформу по наличию инструментов:
  - `pbpaste` (macOS)
  - `wl-paste` (Wayland)
  - `xclip` (Linux X11)
- Если буфер содержит изображение, оно сохраняется во временный файл, а путь возвращается в `imagePath`.
- Если буфер содержит текст, он возвращается в `text`.

**Пример:**
```go
text, imagePath, err := pasteFromClipboard()
if err != nil {
    log.Fatal(err)
}
fmt.Println("Text:", text)
fmt.Println("Image:", imagePath)
```

## Внутренние функции

### pasteMac

```go
func pasteMac() (string, string, error)
```

Читает буфер обмена macOS.

**Порядок выполнения:**
1. Вызывает встраиваемый скрипт на Swift для извлечения изображения (любой UTI: PNG, JPEG, TIFF, PDF).
2. Если изображение найдено и валидно, возвращает путь к сохранённому файлу.
3. В качествеallback-а использует `pbpaste` для получения текста.
4. Если `pbpaste` случайно вернёт байты изображения, их проверяют по PNG-заголовку и сохраняют.

---

### pasteMacImage

```go
func pasteMacImage() (string, error)
```

Выполняет встраиваемый Swift-скрипт для чтения изображения из буфера обмена macOS.

**Возврат:**
- Путь к сохранённому файлу изображения или пустая строка, если изображения нет.
- Ошибку, если Swift не установлен или скрипт не выполнился корректно.

---

### pasteWayland

```go
func pasteWayland() (string, string, error)
```

Использует `wl-paste` для чтения буфера обмена Wayland.

**Порядок выполнения:**
1. Спрашивает текст через `wl-paste --no-newline`.
2. Проверяет, является ли ответ бинарными байтами изображения (PNG-заголовок).
3. Если изображение найдено, сохраняет его и возвращает путь.
4. В противном случае возвращает текст.
5. Если первый вызов неудачен, пытается запросить изображение напрямую через `wl-paste --type image/png`.

---

### pasteX11

```go
func pasteX11() (string, string, error)
```

Использует `xclip -selection clipboard` для чтения буфера обмена X11.

**Порядок выполнения:**
1. Спрашивает изображение через `xclip -selection clipboard -o -t image/png`.
2. Если получены данные и это изображение, сохраняет его.
3. Если изображения нет, спрашивает текст без типа.

---

### saveImageBytes

```go
func saveImageBytes(data []byte) (string, error)
```

Сохраняет байты изображения во временный файл.

**Поведение:**
- Проверяет, что данные являются валидным PNG через `image.DecodeConfig`.
- Создаёт директорию в `/tmp/automata-clip`.
- Сохраняет файл с именем `paste-<timestamp>.png`.
- Декодирует и перекодирует изображение через `png.Encode`, чтобы убедиться в валидности и очистить мусор.
- Возвращает путь к сохранённому файлу или ошибку.

---

### handlePaste

```go
func (e *Emulator) handlePaste() tea.Cmd
```

Обработчик пасты в TUI на основе Bubble Tea.

**Поведение:**
- Получает содержимое буфера обмена через `pasteFromClipboard`.
- Если ошибка или пустой результат, возвращает `nil`.
- Если содержимое — изображение, записывает путь к файлу в PTY (без bracketed paste).
- Если содержимое — текст, использует bracketed paste (ESC[200~...ESC[201~).

## Встраиваемый Swift-код

```go
const clipboardImageSwift = `import Cocoa
import Foundation

let pb = NSPasteboard.general
let candidates: [(NSPasteboard.PasteboardType, String)] = [
    (NSPasteboard.PasteboardType("public.png"), "png"),
    (NSPasteboard.PasteboardType("public.jpeg"), "jpg"),
    (NSPasteboard.PasteboardType("public.tiff"), "tiff"),
    (NSPasteboard.PasteboardType("com.adobe.pdf"), "pdf"),
]
for (t, ext) in candidates {
    if let data = pb.data(forType: t) {
        let url = FileManager.default.temporaryDirectory
            .appendingPathComponent("automata-paste-\(UUID().uuidString).\(ext)")
        do {
            try data.write(to: url)
            print("PATH:\(url.path)")
        } catch {
            print("ERR:\(error)")
        }
        exit(0)
    }
}
print("NO_IMAGE")
`
```

**Назначение:**
- Извлечение изображений из буфера обмена macOS через Cocoa API.
- Поддержка форматов: PNG, JPEG, TIFF, PDF.
- Сохранение изображения во временный файл с UUID-именем.

## Архитектурные решения

### 1. Поэтапная проверка инструментов

Функция `pasteFromClipboard` использует стратегию `try-catch` с приоритетом:
- macOS → Wayland → X11

Это позволяет корректно работать на разных платформах без явного определения ОС.

### 2. Обработка изображений

Изображения сохраняются во временную директорию `/tmp/automata-clip/` с правами `0644`.
Имена файлов включают временную метку в наносекундах.
Изображения перекодируются через `png.Encode` для гарантии чистоты данных.

### 3. Bracketed Paste

Текст использует bracketed paste (ESC-последовательности) для корректной интеграции с TUI.
Изображения передаются через путь к файлу.

### 4. Изоляция платформоспецифичного кода

Платформоспецифичная логика вынесена в отдельные функции:
- `pasteMac`, `pasteMacImage`
- `pasteWayland`
- `pasteX11`

Это позволяет легко добавлять поддержку новых платформ.

### 5. Swift-скрипт как обходной путь

macOS `pbpaste` возвращает только текстовое представление.
Для извлечения изображения используется встраиваемый Swift-скрипт, который делает round-trip через Cocoa API.

---

## Ключевые правила

1. **Поэтапная проверка инструментов** — не полагайтесь на одну платформу.
2. **Валидация изображений** — всегда проверяйте PNG-заголовки и перекодируйте.
3. **Темперные файлы** — используйте `/tmp` с уникальными именами.
4. **Bracketed paste** — используйте ESC-последовательности для текста в TUI.
5. **Изоляция платформоспецифичного кода** — выносите логику в отдельные функции.

## Примечания

- Код работает только на платформах с соответствующими инструментами буфера обмена.
- Изображения сохраняются во временную директорию и должны быть удалены после использования (по желанию).
- Swift требуется для работы с изображениями на macOS.
