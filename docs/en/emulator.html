Emulator - Terminal Emulator

Emulator is a built-in terminal emulator implemented in Go. It runs a shell/command in a PTY (pseudo-terminal) and renders the output. It is independent of any UI framework; hosts feed it keyboard/mouse/resize messages and call View(width, height) to render it.

Overview

The emulator provides:

  • Full terminal emulation with PTY support
  • Keyboard input handling including clipboard paste (Ctrl+V)
  • Mouse support with drag selection
  • Scrollback buffer with configurable limit
  • Command history tracking
  • CWD (current working directory) tracking via OSC 7
  • ASCII art idle state when stopped

View

View renders the terminal screen at the given panel size. The screen size is kept in sync by ResizeMsg from the warp layout engine; during a drag the panel is filled by warp's padContent and the real resize happens on release.

Key Handling

The emulator supports full keyboard input:

  • Arrows (Up, Down, Left, Right)
  • Home, End, Page Up, Page Down
  • Delete, Insert
  • Tab, Shift+Tab
  • Enter (newline)
  • Backspace, Escape, Space
  • Ctrl+C, Ctrl+D, Ctrl+J, Ctrl+L, Ctrl+Z
  • Character runes

Ctrl+V pastes from the clipboard. This is a special case handled directly before normal key processing.

Mouse Handling

The emulator supports mouse input via SGR mouse sequences:

  • Left, Middle, Right button clicks
  • Wheel up/down
  • Press, Motion, Release events

Drag selection works as follows:

  1. Mouse press: records position, does not start selection
  2. Mouse motion: if moves more than 1 cell from press position, starts selection
  3. Extend selection as mouse moves
  4. Mouse release: copies selection to clipboard

Scrollback

Scrollback is controlled via mouse wheel or programmatic calls:

  • scrollUp(lines int) - scroll up by given lines
  • scrollDown(lines int) - scroll down by given lines
  • resetView() - reset the view (called on keystroke)

Command History

Commands entered in the terminal are tracked in commandHistory (max 1000 entries). The history is captured when Enter is pressed, and the prompt prefix is stripped.

Callbacks:

  • OnCWDChange(path string) - called when working directory changes
  • OnCommandHistoryChanged(history []string) - called when command history changes

Implementation Details

PTY Configuration

The emulator configures the shell to emit OSC 7 with the current directory after each prompt:

osc7Cmd := `echo -ne "\033]7;${PWD}\007"`
env = append(env, "PROMPT_COMMAND="+osc7Cmd)

Key Encoding

Keyboard events are converted to terminal byte sequences:

func keyToBytes(msg tea.KeyMsg) []byte {
    switch msg.Type {
    case tea.KeyUp:
        return []byte("\x1b[A")
    case tea.KeyDown:
        return []byte("\x1b[B")
    // ... more keys
    }
}

Mouse Encoding

Mouse events are encoded as SGR mouse sequences:

func mouseToBytes(msg tea.MouseMsg) []byte {
    var cb int
    switch msg.Button {
    case tea.MouseButtonLeft:
        cb = 0
    case tea.MouseButtonMiddle:
        cb = 1
    case tea.MouseButtonRight:
        cb = 2
    case tea.MouseButtonWheelUp:
        cb = 4
    case tea.MouseButtonWheelDown:
        cb = 5
    default:
        cb = 3
    }
    // ... build sequence
    seq := fmt.Sprintf("\x1b[<%d;%d;%d%c", cb, x, y, suffix)
    return []byte(seq)
}

Thread Safety

The Emulator uses an sync.RWMutex for thread safety:

  • Write locks (Lock/Unlock) for state mutations
  • Read locks (RLock/RUnlock) for read-only access

Important: The parser callback is invoked without holding the mutex to avoid deadlocks, since the callback may call back into emulator methods that also take the mutex.
