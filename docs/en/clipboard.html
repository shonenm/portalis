Clipboard

This module provides clipboard operations for cross-platform text and image handling. It supports macOS, Linux, and Wayland environments, with automatic detection of the available clipboard tool.

Package Overview

The clipboard package in the portalis module implements system clipboard reading and writing. It is designed to work with a TTY emulator that uses bracketed paste sequences for text input.

Key capabilities:

  • Cross-platform clipboard support (macOS, Linux, Wayland)
  • Image clipboard handling via temporary files
  • Automatic detection of available clipboard tools
  • Bracketed paste integration for terminal applications

Public API

copyToClipboard

func copyToClipboard(lines []string)

Sends the given lines (newline-joined) to the system clipboard.

Parameters:

  • lines []string - slice of text lines to copy, joined with newlines

Behavior:

  • Empty input is ignored (no-op)
  • Tries to find an available clipboard tool in this order:
  1. pbcopy (macOS native)
  2. xclip (Linux X11)
  3. xsel (Linux X11 alternative)
  4. wl-copy (Wayland)

The function returns after the first successful copy operation.

pasteFromClipboard

func pasteFromClipboard() (text string, imagePath string, err error)

Returns the clipboard contents. If the clipboard contains an image, it is saved to a temp file and the file path is returned as imagePath. Otherwise the plain-text contents are returned as text.

Return values:

  • text - clipboard text content (empty string if image)
  • imagePath - path to saved image file (empty string if text)
  • err - error if no clipboard tool is available

Platform detection order:

  1. macOS: uses inline Swift script for image detection
  2. Wayland: uses wl-paste
  3. X11: uses xclip

handlePaste

func (e *Emulator) handlePaste() tea.Cmd

Reads the clipboard and writes either the text or the image file path to the PTY (bracketed paste for text, plain path for images).

Method receiver:

  • e *Emulator - the emulator instance

Return value:

  • Returns a tea.Cmd that writes to the PTY, or nil if no PTY is available

Bracketed paste format:

ESC[200~{text}ESC[201~

Implementation Details

Platform-Specific Clipboard Readers

macOS (pasteMac)

macOS clipboard handling uses a two-step approach:

  1. First, tries the inline Swift script (pasteMacImage) to detect any image UTI
  2. Falls back to pbpaste for text content

The Swift script checks for these image types:

  • public.png
  • public.jpeg
  • public.tiff
  • com.adobe.pdf

Wayland (pasteWayland)

Wayland clipboard handling uses wl-paste with two attempts:

  1. Text first: wl-paste --no-newline
  2. If that fails, try wl-paste --type image/png

Text output is checked for PNG signature to detect embedded images.

X11 (pasteX11)

X11 clipboard handling uses xclip:

  1. First tries to read PNG: xclip -selection clipboard -o -t image/png
  2. Then reads plain text: xclip -selection clipboard -o

Image Handling (saveImageBytes)

The saveImageBytes function:

  • Validates PNG data using image.DecodeConfig
  • Creates a temp directory under os.TempDir() named automata-clip
  • Saves image with timestamp-based filename
  • Decodes and re-encodes via PNG to strip any invalid bytes
  • Permissions: 0644 for files, 0755 for directories

Error Handling

Errors are returned for:

  • No clipboard tool found
  • Swift script execution failure
  • Image save failure
  • PNG validation failure

Dependencies

The package depends on:

  • github.com/charmbracelet/bubbletea - for TTY emulator integration
  • Standard library: bytes, fmt, image, image/png, os, os/exec, path/filepath, strings, time

Temporary Files

Images are saved to a temporary directory:

/tmp/automata-clip/

Files are named with timestamps and are cleaned up on save failure or when the function returns an error.

Notes

  • macOS pbpaste only returns text representation, not raw image bytes
  • On Wayland, text is checked for PNG header to detect image data
  • The emulator must have a PTY attached for handlePaste to work
  • Empty clipboard (no text, no image) results in nil command being returned
