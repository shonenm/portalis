ANSI Parser

The ansi package provides a state machine-based parser for ANSI escape sequences. It processes terminal input and updates a Screen object accordingly, handling text rendering, cursor movement, screen clearing, color sequences, and OSC (Operating System Commands).

Module Overview

This parser implements a character-by-character state machine to decode ANSI escape sequences. The parser maintains internal state to handle:

  • Normal mode: Rendering regular characters, handling line endings, tabs, backspaces
  • Escape mode: Detected when encountering ESC (0x1b), awaiting CSI/OSC prefix
  • CSI (Control Sequence Introducer) mode: Parsing control sequences like cursor movement, screen clearing, SGR (Select Graphic Rendition)
  • OSC (Operating System Command) mode: Handling OSC sequences including directory change notifications (OSC 7)
  • Paste mode: Handling bracketed paste sequences (CSI 200~ to CSI 201~)

Parser Type

type Parser struct {
    screen    *Screen
    state     ansiState
    buf       strings.Builder
    utf8Buf   []byte
    onCWD     func(string)
    lastCWD   string
}

The Parser struct maintains:

  • screen - Reference to the Screen object being updated
  • state - Current parsing state (Normal, Escape, CSI, OSC, Paste)
  • buf - Buffer for accumulating CSI/OSC sequence bytes
  • utf8Buf - Buffer for accumulating incomplete UTF-8 sequences
  • onCWD - Optional callback for working directory changes
  • lastCWD - Last known working directory from OSC 7

Public API

func NewParser(screen *Screen) *Parser

Creates a new ANSI parser for the given screen. This is the main entry point for creating a parser instance.

func (p *Parser) Feed(data []byte)

Feeds raw bytes into the parser. The parser processes each byte according to the current state machine. This method is the primary way to provide input to the parser.

func (p *Parser) SetCWDCallback(fn func(string))

Sets a callback function that will be invoked when the working directory changes (detected via OSC 7 sequences). The callback receives the new directory path as a string.

State Machine

The parser uses a finite state machine with the following states:

State Description
stateNormal Normal text rendering mode. Handles printable characters, line endings, tabs, backspaces.
stateEscape Encountered ESC (0x1b). Awaiting CSI ([), OSC (]), or returning to normal.
stateCSI CSI sequence mode. Accumulating bytes until final byte (0x40-0x7e).
stateOSC OSC sequence mode. Accumulating bytes until BEL (0x07) or ESC \.
statePaste Bracketed paste mode. Characters are rendered literally until ESC [201~.

Key CSI Sequences

The parser handles various CSI (Control Sequence Introducer) sequences:

SGR (Select Graphic Rendition) - CSI m

Handles text styling and colors:

  • 0 - Reset all attributes
  • 1 - Bold
  • 2 - Dim
  • 3 - Italic
  • 4 - Underline
  • 5 - Blink
  • 7 - Reverse
  • 8 - Hidden
  • 9 - Strikethrough
  • 22-29 - Reset corresponding attributes
  • 30-37, 90-97 - Foreground colors (ANSI 8-bit and 16 colors)
  • 38;5;N - 256-color foreground
  • 38;2;R;G;B - Truecolor foreground
  • 40-47, 100-107 - Background colors
  • 48;5;N - 256-color background
  • 48;2;R;G;B - Truecolor background

Cursor Movement - CSI A/B/C/D/E/F/G/H

  • A - Cursor up
  • B - Cursor down
  • C - Cursor forward
  • D - Cursor backward
  • E - Cursor down and to first column
  • F - Cursor up and to first column
  • G - Cursor to column N (1-indexed)

Screen Operations - CSI J/K

  • J 0 - Clear from cursor to end of screen
  • J 1 - Clear from cursor to beginning
  • J 2 - Clear entire screen, move cursor to (0,0)
  • K 0 - Clear from cursor to end of line
  • K 1 - Clear from beginning of line to cursor
  • K 2 - Clear entire line

Scrolling - CSI M

  • M - Reverse line feed / scroll down

Scroll Region - CSI r

  • r - Set scroll region (top, bottom rows)

Private Modes - CSI ?h/l

  • ?1049h/l - Alternate screen buffer (DECALTS/DECRALT)
  • ?2026h/l - Synchronized output modes

OSC Sequences

The parser handles OSC (Operating System Command) sequences, specifically:

  • OSC 7 - Working directory change notification. The payload format is typically file://hostname/path or /absolute/path. The extractOSC7Path function normalizes these to absolute paths.

Parses CSI/OSC parameter strings separated by semicolons into a slice of integers. Empty segments are treated as 0. Invalid numbers default to 0.

Internal Functions

func (p *Parser) feedByte(b byte)

Private method that processes a single byte. This is the core of the parser, called from Feed for each byte in the input.

func (p *Parser) flushUtf8()

Flushes any incomplete UTF-8 sequence by emitting replacement characters (\ufffd). This is called when a character is interrupted by control characters.

func (p *Parser) clearFromCursor()

Clears all cells from the current cursor position to the end of the screen.

func (p *Parser) handleSGR(params []int)

Processes SGR (Select Graphic Rendition) sequences, applying text styling and color attributes to the cursor.

func (p *Parser) handleCSI(seq string)

Handles CSI control sequences after the final byte is received. Extracts parameters and final byte to determine the action.

func (p *Parser) handleOSC(payload string)

Handles OSC (Operating System Command) sequences, specifically OSC 7 for working directory changes.

func extractOSC7Path(s string) string

Extracts an absolute filesystem path from an OSC 7 payload. Handles both file://hostname/path and /absolute/path formats.

Implementation Details

UTF-8 Handling

The parser accumulates bytes in utf8Buf while processing UTF-8 multi-byte sequences. When a complete valid sequence is formed, it is decoded and rendered. If a control character arrives while collecting a UTF-8 sequence, the incomplete bytes are flushed as replacement characters.

State Transitions

  • stateNormal → stateEscape on ESC (0x1b)
  • stateEscape → stateCSI on [
  • stateEscape → stateOSC on ]
  • stateEscape → stateNormal on unknown escape
  • stateCSI → stateNormal on final byte (0x40-0x7e)
  • stateOSC → stateNormal on BEL (0x07) or ESC \
  • stateNormal → statePaste on CSI 200~
  • statePaste → stateNormal on CSI 201~

Line Ending Handling

The parser handles different line ending styles:

  • \r (CR): Resets column to 0
  • \n (LF): Increments row; if wrapPending is true, also resets column and clears pending wrap
  • \r\n (CRLF): Handled via the pending wrap flag

Tab Handling

Tab characters move the cursor to the next tab stop, calculated as (col/8 + 1) * 8, but never beyond the screen width.

Backspace Handling

The backspace character (0x08) decrements the cursor column. This is a simplified implementation that does not support multi-byte character backspacing.

Color Format Support

The parser supports multiple color formats through SGR code 38 and 48:

  • 38;5;N - 8-bit ANSI color (N from 0-255)
  • 38;2;R;G;B - Truecolor (24-bit RGB)
  • 48;5;N - 8-bit ANSI background
  • 48;2;R;G;B - Truecolor background

Usage Example

package main

import (
    "./portalis"
    "./portalis/screen"
)

func main() {
    screen := &screen.NewScreen(24, 80)
    parser := portalis.NewParser(screen)
    
    parser.SetCWDCallback(func(cwd string) {
        fmt.Println("Working directory changed to:", cwd)
    })
    
    data := []byte{
        0x1b, "[", "3, 8, ;", 5, ;", 196, ;", 1, m, H, e, l, l, o, !, ",
        0x1b, "[", 7, ;", file://localhost//home/user, "\x07",
    }
    
    parser.Feed(data)
}
